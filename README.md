# 📸 معرض الصور الذكي - Glassmorphism

معرض صور متجاوب بتصميم زجاجي Glassmorphism يسحب الصور مباشرة من GitHub.

## ✨ المميزات
- **تصميم زجاجي**: تأثير Blur شفاف مع حدود مضيئة
- **متجاوب**: يشتغل على الجوال والكمبيوتر
- **تحميل من GitHub**: يسحب الصور مباشرة من الريبو
- **Lightbox**: عرض الصور بحجم كامل عند الضغط
- **تأثيرات Hover**: أنيميشن ناعم للكروت

## 🚀 العرض المباشر
[شاهد المعرض على Vercel](ضع رابط موقعك هنا)

## 🛠️ طريقة الاستخدام
1. ارفع صورك للريبو وسمها `1.jpg`, `2.jpg`, `3.jpg` ... إلخ
2. عدّل مصفوفة `imageNumbers` في ملف `index.html` وحط أرقام الصور
3. غيّر `repoName` لاسم الريبو حقك
4. ارفع `index.html` على Vercel أو GitHub Pages
